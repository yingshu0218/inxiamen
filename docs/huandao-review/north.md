# XM-012 观音山至五缘大桥东桥头

本页保留首轮北段交付的入口、指标及指纹。XM-011 实飞发现五缘大桥中跨断口，当前复验使用[五缘大桥修复包](wuyuan-bridge.md)。

基准日为 2026-11-25。由航线图选择“环岛路 · 白城起飞”，在原有 21.48 公里连续航线上经过观音山，再向北至五缘大桥。观音山路口至桥头的主路双向平均约 5.37 公里，计入全走廊原有的 19.70 公里。五通路口、天桥和桥下折返均已进入生产场景。[北段底图与前后对照](north-alignment.jpg) · [分段数据](../../src/coast/north.json)

- 射线检查使用现场景生成的主路、岸墙、木浦天桥和既有五缘大桥网格。北段 1,751 个路面采样点均在 DEM 上方。两幅桥头横断面各取五点，在缝前后各 0.15 米测得的最大高差分别为 0.028 米和 0.026 米。三条辅路线首尾接点间距为零，里程合计 5.685 公里，含双侧及折返段。机动车掉头线与两幅桥的交点净空分别为 3.49、4.06 米，步骑线为 3.25、3.41 米。木浦桥跨四幅主辅路的模型净空为 5.50 至 6.34 米。上述数值仅描述游戏网格。[离线检查](../../tools/check-huandao-north.mjs)
- `python3 tools/check-huandao-shore.py` 需要 Pillow。复算 8 个沙面与生产遮罩逐像素一致。公园两条取样线共 550 点，离游戏水线最少 29.1 米。北段遮罩范围内的 2,100 个主路中心采样均在沙面外。桥头沿岸慢行线的 154 个样本均有地形或岸墙承托。[岸滩结果](north-shore.json)
