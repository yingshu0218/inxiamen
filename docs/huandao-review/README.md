# XM-012 厦门环岛路滨海走廊

2026-11-25 更新：XM-011 已验过五缘大桥主跨和两端接线。桥下第二次返工的生产候选、四组实机前后对照及独立复验入口见[桥下铺面复查](wuyuan-lower/README.md)。

交付基准日为 2026-11-25。XM-011 已在整合包实飞北段并退回五缘大桥断口，修复包已通过跨水全段离线检查，待同机位复验。[五缘大桥修复入口与证据](wuyuan-bridge.md)

由游戏首页打开观光航线图，选 **环岛路 · 白城起飞**。飞机从白城外海向东，经过胡里山、曾厝垵、黄厝、椰风寨、会展、观音山、五通，到五缘湾。正常生产入口也接受 `?tour=huandao`。黄厝原有向西的空中观光入口仍为 `beach`。新航段已进入正常航线，因而全程观光的时长也有所增加。

本批按市人大沿线规划保护决定第一条界定的白城至五缘湾走廊交付。终点取环岛东路与五缘大桥双幅相接的节点，两向道路长度的平均值为 19.70 公里。省政府 2024-05-10 的游览资料描述 30.8 公里海岸线；历史环岛工程还包括西岸、机场方向的城市道路。本批没有把它们合计为新增精修里程。地图在云顶南路口更换南、东路 way 标签，官方交通报道和运营单位在黄厝、椰风寨仍有使用“环岛南路”的实例，表内采用可复查路口界定分段。精确法定改名桩号尚待道路地名台账确认。[市人大 2010-12-02 决定](https://www.xmrd.gov.cn/pdf_file/qwfb/P020120815591492503081.pdf) · [福建省政府游览资料](https://www.fj.gov.cn/zwgk/ztzl/sxzygwzxsgzx/flsxkmh/202405/t20240510_6446361.htm) · [思明国控 2026-09-29 点位公告](https://simingkonggu.com/news/detail/27033)

白城校门约在游戏坐标 (-2813, 4933)，陆侧属于 XM-001。机动车道始于大学路口，接入既有桥头连接线，演武桥面和平台由 XM-005 负责。观音山路口过街节点约 (6777, -1819)，岸线位于其东侧，路西商务楼群由 XM-013 负责。

## XM-011 复查

1. 在同一场飞行中从 XM-005 的演武桥东端转向白城校门，核对白城天桥、沙滩与 XM-001 校门；进入自由移动后可从航线图选“白城至曾厝垵 · 总览”和低空机位，再返回原飞行。
2. 由航线图选择“环岛路 · 白城起飞”可单独启动连续航段。白城出发后陆地在左，依次观察渔桥、黄厝及椰风寨、会展中心、观音山沙滩桥和五缘湾。若在自由移动模式，先返回飞机，再选起飞入口。
3. 机位可用 `?tour=<机位 ID>` 直达，选 `?tour=zengcuoan-fish&time=night` 复查灯光。重点看步道与桥梯衔接、近地路面闪烁、工地和商务区接口、竖屏选点及返回。

`npm run build` 完成生产打包。运行 `node tools/check-huandao.mjs` 可复算分幅端点、机位净空、网格数值和无风自动飞行；[离线结果](offline.json)。飞行逻辑采用实际 Flight，地表取项目 DEM，障碍取本模块新增对象，字牌画布在离线检查中使用占位上下文。另以生产岸距 PNG 和游戏的 5 米岸坡采样复算白城新台阶，上缘与骑行步道同高，末级与沙面高差约 0.023 米。正式整城浏览器画面、GPU 色彩与照明、实飞遮挡及移动端操作留给 XM-011 独立验收。
