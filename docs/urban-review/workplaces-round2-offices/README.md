## 集成与限制

合并点为 `city-layout.js` 的新轮廓检测、`scenery-landmarks.js` 的地标注册及 `route.js` 的新增机位。第一轮施工范围位于新窗之外，既有八条完整键继续使用。底库、路网和观音山专项沿用共同基线。若共同底库重排记录则保留完整轮廓键，若重绘四条轮廓则须重新核查相交并更新键。

固定机位海拔 246 m，目标 (6582, 100, −3098)，垂直视角 43°。平面检查至机动车道路至少 4.30 m，与道路和游戏内陆水面无相交。跨桥连接两个中央塔水平投影，桥下保持露空。游戏构建和两版同相机画面、源数据与性能记录见本轮验收工件。实测楼脚、桥内设施、逐楼开业、夜景及硬件帧率留待核验。
