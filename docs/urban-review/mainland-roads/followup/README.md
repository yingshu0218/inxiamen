## 成功大道吕岭路口

既有瓦片按道路级别渲染，把多条单车道匝道画成 13.6 或 18 米宽。2025-08-06 的正射影像可分辨地面匝道、吕岭路分幅车道、成功大道高架和横跨的慢行设施。OSM 线位注明相关匝道为单车道。本批把五条来源道路切分后落入游戏的八段匝道改为 4.6 米估绘铺面，并补回瓦片简化掉的两个接点 `(769, -1671)` 和 `(785, -1676)`。另外两个既有接点 `(770, -1675)`、`(785, -1669)` 参与回归。匝道沿各自的接点接向对应分幅。高架、地面道路与慢行桥各自保留原层别。4.6 米是依据单车道分类选定的游戏值，没有现场测宽。[匝道 1](https://www.openstreetmap.org/way/127162238) · [匝道 2](https://www.openstreetmap.org/way/127162248) · [匝道 3](https://www.openstreetmap.org/way/128826955) · [匝道 4](https://www.openstreetmap.org/way/128827209) · [匝道 5](https://www.openstreetmap.org/way/129281105) · [成功大道现场资料](https://news.xmnn.cn/xmxw/202609/t20260924_452678.html)

## 验证

同一批 268,506 个通用道路探针重算，上一版 18 个埋地点和 4 个占水点此次均未检出。此结果覆盖同一批探针。匝道检测另行检查八段宽度、原路层和四个与吕岭路分幅的共用节点。上版筼筜湖专用步道回归 187 个样点并检查端点。可从仓库根目录运行 `node tools/audit-mainland-roads.mjs`，所需本地数据和 Pillow 同上版。[当前网格结果](grid.csv) · [当前问题与核验记录](findings.json)

吕岭路前后取景为同一自由视角。相机 `(751, -1770, 140)`，目标 `(773, -1673, 6)`。坡地和水缘点使用数值复查。本批未逐个校核全岛交通标线、测量立交实际净空或重建地下隧道。[吕岭路同机位对照，左旧右新](luling-comparison.webp)
