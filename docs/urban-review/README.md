**最影响近景的是一个屋顶在底库里被拆成碎块，以及真正的楼间空地里出现沿路估算的房子。** 样区地图小区边界较完整，逐栋地图建筑较少。和航片叠看，部分 CMAB 屋面只覆盖长条住宅的几段，个别轮廓伸入厦禾路。Overture 的东亚建筑数据在部分楼列补出了较完整的长轴和街墙，也包含过于概括的矩形。融合时保留原有地图建筑、架空部分和带内环的建筑，对相交不足以解释原有屋面的候选予以舍弃。滑动、缩放时建筑朝向来自同一组环坐标。

改前 XMC1 共 30,089 条，地图 8,269 条、CMAB 影像 20,606 条、沿街估算 1,214 条。有来源的轮廓为 28,875 条。运行时对一般建筑没有按距离改成矩形的分支，凹形屋面和孔洞通过三角剖分绘制。旧的距离切换发生在平面距离 6.5 公里附近，按 1,080 米网格整批隐藏高度低于 24 米且外环面积低于 950 平方米的建筑。这个机制会影响远方天际线，在样区内拉高镜头并不会触发它。

### 飞越、缩放与距离切换

在同一桌面 Chromium 浏览器内沿厦禾路 BRT 的 17 个原始线路节点插值移动，海拔从 315 米上升至约 995 米再下降，视角在 32° 至 68° 间往返。每版先预热一遍，再取三遍共 273 个浏览器动画帧间隔。视窗 1800 × 974，绘图缓冲 1620 × 876，两次均固定像素比 0.9。中位帧耗由 **34.1 → 33.6 毫秒**，P95 由 **42.4 → 43.5 毫秒**。这次本机测量的长帧略慢，不代表移动端表现。[改前帧耗](before-frames.json) · [改后帧耗](after-frames.json)

另沿东西方向拉远 5.2、7.1、8.5 公里后返回，读取样区小窗内处于可见建筑批次的几何顶点数。旧版由 18,131 降到 12,562 再恢复。改后四批复核区的楼加入常驻建筑批次，样板小窗五次均为 18,516。此项在视锥裁剪之前计数，只检查距离开关。其余城区继续使用原加载策略。[改前距离测试](before-lod.json) · [改后距离测试](after-lod.json)

## 高度、来源与复建

全库 31,091 条，其中 8,269 条原地图、20,127 条 CMAB、1,541 条 Overture 和 1,154 条沿路估算。高度来源分别为公开高楼资料 8 条、地图高度或层数 253 条、遥感模型 22,538 条、邻楼或保守估值 8,292 条。用途、屋顶颜色、窗格样式及楼层观感仍有推断成分。遥感提取的是屋面，高楼视差、数据年份差异和相邻屋面粘连会保留在结果中。本轮验收覆盖日间建筑和几何遮挡；既有夜间地面亮度纹理未逐楼复核。[统计清单](../../public/geo/city-layout.json) · [完整署名及许可](../../public/geo/credits.json)

样板 477 个 Overture 轮廓中，160 个继承对应遥感屋面的高度，317 个使用估值。源屋面匹配优先于邻里估算。缺高度时，在 190 米内查找面积和用途相近的楼，遇到有边界的小区或厂区则限定在同一地块，取最近至多 7 个样本的中位数。没有可用参照时，工业、住宅、其他用途分别取 12、18、9 米。地块缺少用途时无法可靠辨认同一小区。形状保留半米精度，楼高精度字段为 0.1 米。

输入采用 Overture 2026-11-18.0 建筑主题及 2026-11-24 获取的 OSM 用地和路网快照。Overture 在四个窗口分别返回 1,451、2,246、1,718、149 个候选要素，包含东亚建筑数据和 OSM。只采用通过预留和已有屋顶匹配检查的轮廓。未获证实的沿路补楼在复核区撤除。数据筛选用的几何与属性保存在项目内，浏览器只加载最终的 XMC1 文件。[Overture 建筑主题](https://docs.overturemaps.org/guides/buildings/) · [东亚建筑数据](https://doi.org/10.5281/zenodo.8174931) · [CMAB V7](https://doi.org/10.6084/m9.figshare.27992417.v7)

按项目 README 先重建基础 city-layout，随后执行以下命令。也可以用 `--input` 和 `--manifest` 指向另存的基础二进制与清单。默认读取仓库内的源快照，集美使用既有 CMAB 缓存，首次运行按原提取器校验和补取厦门市文件。XMC1 中标志位 2 表示 Overture 轮廓、位 3 表示进入复核区域的常驻批次。四片区重建的二进制与生产服务提供的文件 SHA-256 相同。

```sh
uv run tools/prepare-district-buildings.py
npm run build
```
