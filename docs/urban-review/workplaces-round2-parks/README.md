# XM-本岛办公园区-02B · 火炬园产业线

共同基线 `06569a49390efa584719db0b6acd8027be15e58a`，实景核查基准为 2026-11-25。正常入口为「起飞大厅 → 从高崎起飞 → 航线图 → 城市地标 → 火炬园 · 荟智空间」，直达参数 `?tour=torch-huizhi&time=afternoon`。

本次实做新丰路 178 号 **火炬荟智空间一期 1 号楼**。地块窗口 `-648,-4478,-474,-4327`，位于第一轮高新广场以北。新模型表达向东开口的研发楼群、高低分明的裙脚和立面、棕色入口带、屋顶光伏及开放的入口前坪和庭院。基线中是一条 12.3 m 的 CMAB 楼体 7243，窗内其余两条邻楼保留。按完整轮廓键移除旧楼体。两轮施工窗口互不交叠，第一轮八条替换键仍在原处生效。
