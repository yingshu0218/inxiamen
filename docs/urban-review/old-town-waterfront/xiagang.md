# 鹭江道南段、厦港街巷与沙坡尾

本批从上一版中山路西口和沙坡尾内岸之间补齐街道模型。工作范围是鹭江道南端至演武引桥的衔接、寿山路口、民族路、铁路文化公园步道及西口，以及大学路和蜂巢山路在避风坞东北侧的接点。车行道、步道、局部地形和路口两块绿地分别按其用途绘制。绿化留出车道和步道，避风坞水面排除散布树木。
