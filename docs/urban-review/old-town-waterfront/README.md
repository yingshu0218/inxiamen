# 中山路西口、鹭江道和沙坡尾内岸

本批从中山路西口沿鹭江道向南取样，至沙坡尾避风坞内岸。基线为 `435f621`。既有沙坡尾向东经过演武、白城的自由航拍已有[验收记录](../../acceptance/2026-11-25/merged-live/README.md)。本批修中山路支路并入滨水大道的路缘，并补避风坞内东北岸约 289 米的临水步行带。两段之间保留已有路网。

## 地图与时相

- 中山路西口。OpenStreetMap 的支路与鹭江道内侧车道共用节点 12360527880，节点编辑于 2024-11-21。2025-03-20 的正射影像可辨支路开口、临街建筑和大道中央分隔带。按游戏既有支路宽度和方向裁开内侧人行道，支路路面向主路标高渐变。中央分隔带沿用既有模型。[支路](https://www.openstreetmap.org/way/127162454) · [接入节点](https://www.openstreetmap.org/node/12360527880) · [内侧车道](https://www.openstreetmap.org/way/183328696)
- 沙坡尾。东北岸折线取 OSM 海岸线 334467977 的节点 1408154417 至 1777545338，取自 2024-09-30 编辑的线位。2025-03-20 影像可辨狭长内水、临街东北岸及对岸工地。记者于 2024-11-25 在现场看到栈道使用，报道披露竹材铺板与绳栏更新。模型以沿岸窄铺面、绳栏和岸墙表现临水步行带，并在既有 25 米地形网格内调整该岸局部高度。宽 2.8 米、标高、柱距与小范围接坡均为观光尺度估算。项目报道的 800 余平方米为工程总面积。港口临时构筑物的后续变化、当前潮位、通航及 2026 年开放情况待核。[岸线](https://www.openstreetmap.org/way/334467977) · [改造后现场报道](https://news.xmnn.cn/xmxw/202411/t20241126_282011.html) · [港口施工与调蓄记录](https://news.xmnn.cn/xmxw/202402/t20240208_127184.html)

## 复查

从正常大厅的航线图选中山路或鹭江道，核对进入沿海自动巡航。选「演武大桥 · 海上看弯桥」，核对进入自由观景。地形和场景模型可以在同一局查看。为便于识别局部变化，本轮画面对照在开发服务器的同一自由视角入口临时指定以下相机与目标，正式包使用原机位。游戏坐标为米，表中三元组依次为 x、z、海拔，视场角 55°。
