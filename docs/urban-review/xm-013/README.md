## 软件园一期

- 细模窗口 `x -1565…-1189，z 4847…5392`。南区位于曾厝垵北路以南、曾厝垵西路以东的狭长地块，北区位于北路以北、白城隧道东口一带环岛干道以南。游戏预留采用串接南北的 OSM 用地轮廓，面积约 10.04 ha。福建投资促进网登记项目总占地 12.7 ha，尚缺可用于逐段比对的地籍边界。[园区招商页](https://fdi.swt.fujian.gov.cn/projects-25145.html) · [一期基底 OSM #565178510](https://www.openstreetmap.org/way/565178510)
- 南区按航片还原弧形楼翼、楼翼前庭、两个南侧大屋顶和由西路进园的前庭路径。北区按航片还原五个可见体量、内部露天空间和临曾厝垵北路的开口。华讯楼、科讯楼、创新大厦见火炬园区资料，元汇、科汇、智汇、通汇见运营公告。当前只做到组团落位，模型体量数按可见屋翼拆分。楼高南区估计 22–30 m，北区估计 37–47 m，屋顶设备间与入口铺装估绘。抽样地面在 8.8–11.6 m，建筑基础按各自地形采样，保留坡向。[火炬高新区园区载体](https://aic.xmtorch.cn/k/zaiti/zhaoshang) · [园区方南北区资产公告](https://www.xmspk.com/ZiChan/nr?UserKey=XS2JB6BUVHW5JGZS)
- 北区通汇楼的创新社区首批合作方于 **2026-07-16** 签约，园区方于 **2026-07-17** 发布报道。智汇楼有 **2026-10-16** 招租和 **2026-11-10** 结果公示，佐证北区现有楼群的使用状态。外部龙虎山路提升改造后，公交于 **2026-04-06** 调整，公告 **2026-04-01** 发布，路线沿环岛南路→曾厝垵西路→曾厝垵北路→龙虎山路。用既有道路和园区开口对齐，软件园范围止于园界。[园区方通汇楼报道](https://www.xsoft.com.cn/ZHXW/PD/Detail?CurrentPD=4DCJTMFRBADU5X7S&UserKey=G5U2RVHHSK7VE3WR&v=6) · [园区方公告列表](https://www.xsoft.com.cn/ZiChan) · [龙虎山路改造后公交调整](https://www.fjdaily.com/app/content/2026-04/01/content_4003205.html)
