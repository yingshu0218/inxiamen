### 湖里火炬园 · 高新广场

窗口 **−574, −4326, −328, −4095**，在新丰路与火炬路交叉口东北侧。福建省自然资源厅记载原 ABB 工业园于 2020 年腾退、2025-04-28 拆除重建项目竣工投用。竣工案例描述 8 层研发厂房、宿舍和改造办公楼。2026-04 招商表称研发主楼 7 层、配套公寓 10 层、另一楼 6 层。这两条楼层口径并存，游戏使用照片和尺度估值。2026-10-16 发布的管委会供图确认研发厂房白色竖向窗带、深色玻璃和红褐基座，原始拍摄日未公布。 [省自然资源厅竣工记录](https://zrzyt.fj.gov.cn/ztzl/sxzygwzxsqzx/zyzxzx/202512/t20251205_7042744.htm) · [厦门投促载体资料](https://www.investxiamen.org.cn/detail/8484.html) · [管委会供图及使用记录](https://fj.people.com.cn/n2/2026/1016/c181466-41723371.html)

- 研发厂房以 33 米主屋顶、12 米内侧低翼及 7 米接合体表达折形主楼和层次。三处可见屋顶设备区以 2 米高体量概化。园区宿舍以 34 米造型保持其独立住用体量。南边改造办公楼沿图中狭长屋顶绘制，两处玻璃楼梯体概化为 19–21 米，主屋顶 17 米。以上均为估高，门牌及构件尺寸未核。
- 露天庭院和前庭约 2,267 平方米，根据影像中的开口和地面色块落位。庭院中央保留开敞，青灰铺装色和接缝是概化，具体运动设施或场地管理用途未核。
- 结合改造案例示意与定年影像描绘可辨屋边。OSM 同次查询未返回可代表落成主厂房的建筑面。Overture 2026-11-18.0 中该点是多块东亚建筑数据，其中 `e1dfc809-d967-42b9-be81-f9ee66e1cfd1` 覆盖新版楼群局部，主楼 L 形的完整轮廓仍缺。CMAB 底库同样只有片段及偏位边缘。旧库记录 7245、7250、7251、7252、7303 从图中对应到这处改造地块，完整几何键存于增量文件。 [CMAB V7](https://doi.org/10.6084/m9.figshare.27992417.v7) · [东亚建筑数据](https://doi.org/10.5281/zenodo.8174931)

## 接入与复查

生产构建运行 `npm ci`、`npm run build`，随后 `npm run preview -- --port 5191`。从起飞大厅点「从高崎起飞」，按 **M**，选「城市地标」下的两个机位。直达入口分别为 [滨北](http://127.0.0.1:5191/?tour=binbei-offices&time=afternoon) 与 [高新广场](http://127.0.0.1:5191/?tour=torch-hightech&time=afternoon)。

增量包含 `src/island-workplaces.json`、绘制模块和机位定义。共享入口只在 `src/city-layout.js` 原始解码遍历中检查完整轮廓键，在 `src/scenery-landmarks.js` 添加两个批次，在 `src/route.js` 注册两个城市地标。若合并时另一批也改动这三个入口，需保留各自的筛选、注册和机位。若共同生成器重写了这八条底库轮廓的坐标、点序或环序，需重新做相交检查并核对删除键。二进制底库、住宅生成器及道路数据均沿用基线。

平面检查以游戏道路中心线按当前道路宽度各向两侧扩展半幅，与新增轮廓及硬地做相交。两处相交均为零，至机动车路面最小间距分别为 6.12 m、12.17 m。至游戏内陆水体的最近距离分别为 128.13 m、79.40 m，新增轮廓和硬地均在现有地标预留以外。八条替换记录在基线逐一命中，替换后新增区域与其余底库轮廓的正面积重叠为零。抽样还核对两处预设相机净空和新楼顶的障碍索引。

几何计数包含普通底库实际生成的网格及两处新增批次。当前底库解码 31,221 条。滨北 228 顶点、114 三角面，高新广场 575 顶点、289 三角面。普通底库由 2,711,337 顶点、1,238,497 三角面变为 2,710,518 顶点、1,238,130 三角面。合计变化为 **2 个批次、减少 16 顶点、增加 36 三角面**。

生产浏览器复查覆盖普通大厅、从高崎起飞、航线图、两个城市地标、返回飞行和返回大厅。对照采用同一 1000 × 562 视窗和绘图缓冲、同一机位、晴朗天气和 14:44 游戏时间。滨北相机海拔 174 m，火炬园 218 m。基线为共同提交的场景加同样两个测试机位。对照原图、并排图、浏览器事件记录、构建 SHA-256 及空间计数随交付包提供。云端 Chromium 使用 SwiftShader 软件 WebGL 2。轻量定帧抽样受软件渲染排队影响，真实设备帧率、macOS 启动器及夜景留待独立验收。

390 × 844 触屏视窗也验证了滨北直达链接及从航线图切到火炬园，两处分别显示海拔 234 m 和 304 m，竖屏游戏实拍随包提供。Linux 云端以 `zsh ./开始飞行.command` 启动原端口 5187，首页、入口分块、游戏分块及建筑库的 HTTP 响应与生产构建逐字节一致。横屏两版和竖屏候选均未记录页面异常、控制台错误或失败请求。
